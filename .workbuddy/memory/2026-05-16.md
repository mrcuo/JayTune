# 2026-05-16 工作日志

## JayTune 图标修复
- **问题**：macOS 应用需要 `.icns` 文件而非 `.appiconset` 目录
- **解决**：使用 `iconutil --convert icns` 从 IconSet.iconset 生成 AppIcon.icns（968K）
- **更新**：build.sh 增加自动生成 .icns 并打包到 Resources/ 的逻辑

## JayTune 国际化 (i18n)
- **新增文件**：
  - `L10n.swift` — 本地化管理器（ObservableObject 单例），支持系统语言自动检测 + 手动切换，UserDefaults 持久化
  - `en.lproj/Localizable.strings` — 英文字符串表
  - `zh-Hans.lproj/Localizable.strings` — 中文字符串表
- **改造文件**：
  - `ContentView.swift` — 全部硬编码中文替换为 L10n 调用；新增 🌐 语言切换按钮 + SettingsView 设置面板
  - `DeviceManager.swift` — 所有状态消息本地化（设备检测、扫描进度、连接状态等）
  - `AlbumView.swift` / `ArtistView.swift` — 返回按钮、计数单位等本地化
  - `JayTuneApp.swift` — 添加 .commands 本地化菜单栏（File/Edit/View/Language 子菜单）；⌘⇧1/2/3 快捷切换语言
- **build.sh 更新**：打包 .lproj 目录到 Resources/；Info.plist 新增 CFBundleDevelopmentRegion + CFBundleLocalizations
- **功能特性**：
  - 自动检测系统语言（中文系 → 中文，其他 → 英文）
  - 手动三种选择：跟随系统 / 简体中文 / English
  - 内嵌 fallback 字符串表（即使 .strings 缺失也能工作）
  - 切换语言后通过 `.id(l10n.effectiveLanguage)` 强制刷新视图
  - 菜单栏 Language 子菜单提供快捷键 ⌘⇧1(系统) / ⌘⇧2(中文) / ⌘⇧3(英文)

## JayTune Phase 5：音乐导出与删除（00:05 - 00:15）
- **新增工具**：
  - `Tools/afc_rm.c` → `afc_rm` 可执行文件 — 使用 libimobiledevice AFC API 删除设备文件
    - 编译命令：`gcc -I/opt/homebrew/Cellar/libimobiledevice/1.4.0/include -I/opt/homebrew/Cellar/libplist/2.7.0/include -L/opt/homebrew/lib -limobiledevice-1.0 -lplist-2.0`
- **DeviceManager 新增**：
  - `isBusy/busyMessage/busyProgress` — 导出/删除操作状态
  - `exportTrack(_:to:)` — 单曲导出（通过 afc_read2 下载）
  - `exportTracks(_:to:)` — 批量导出，带进度回调
  - `deleteTracks(_:)` — 批量删除，自动从本地列表移除
  - `useWiFi` — WiFi 连接模式开关（UserDefaults 持久化）
  - `afcArgs(_:)` — 自动为所有 AFC 工具调用附加 `-n` 网络模式参数
- **ContentView 新增**：
  - 工具栏 📤 导出按钮 + 🗑 删除按钮（选中歌曲时启用）
  - 右键菜单：导出歌曲 / 删除歌曲 / 复制曲目信息
  - 删除确认对话框（单首/多首不同提示文案）
  - NSOpenPanel 目录选择器（选择导出目标文件夹）
  - 导出/删除进度覆盖层
  - 选中计数 badge 显示在状态栏
- **MusicListView 改造**：
  - 新增 `onExportSingle`/`onDeleteSingle` 回调
  - 右键 contextMenu 支持
  - 文件大小列 + 格式化显示
- **MusicTrack 新增**：`exportFilename` 属性（艺术家 - 曲目.扩展名）

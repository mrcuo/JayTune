# 2026-05-17 Daily Log

## JayTune 构建问题修复

### 问题1：桌面出现三个 JayTune
**原因**：`~/Desktop/JayTune.app/` 内错误嵌套了另一个 `JayTune.app`（不在 `Contents/` 里，在 Bundle 顶层）。
Spotlight 把两个都索引进启动台，加上工作区里的副本，共三个。
**修复**：删除嵌套副本 + 工作区旧副本，重新签名。

### 问题2：打开闪退
**原因**：`DeviceManager.init()` 直接调用 `refreshDevices()`，同时 `ContentView.task` 也调用，重复触发。
且 `init()` 里访问 `L10n.shared.localized()` 可能在非主线程。
**修复**：`init()` 不再调用 `refreshDevices()` 和 `L10n.shared`，由 UI `.task` 触发刷新。

### 问题3：图标丢失
**原因**：`AppIcon.icns` 可能损坏 + macOS 图标缓存未刷新。
**修复**：`iconutil --convert icns` 重新生成， `touch App` + `killall Dock` 刷新缓存。

### 其他修复
- `.onChange(of:perform:)` 废弃 API → 新 API（两个参数）
- `Selector()` → `#selector()` + 通知方式（`showPreferencesWindow` 在 Swift overlay 中不可用）
